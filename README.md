# E-Commerce Sales Data Analysis

## Overview
End-to-end exploratory data analysis (EDA) on a 500-record e-commerce sales dataset using Python. The project covers data cleaning, feature engineering, aggregation, and visualization across 12 structured steps.

## Dataset
- **File:** `ecommerce_sales.csv`
- **Records:** 500 orders (510 with duplicates)
- **Columns:** 14 features including order details, customer info, product category, payment method, and order status
- **Issues present:** Missing values, duplicate rows, incorrect data types

## Tech Stack
- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
